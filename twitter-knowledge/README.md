# ナレッジ自動整理ツール

ナレッジシート（スプレッドシート）に拡張機能で溜まっていくURLを、
定期的に自動処理するGASスクリプト。X(Twitter)の投稿だけでなく、
ブログ記事・YouTube動画のURLもそのまま入れてOK（種類は自動判別）。

```
[拡張機能] URLをナレッジシートに保存
    ↓ 6時間ごとに自動実行
[GAS] 未処理のURLを検出し、種類を自動判別
    ├─ X投稿    → 公開シンジケーションAPIで本文・投稿者・日時を取得
    ├─ YouTube  → oEmbed＋動画ページからタイトル・チャンネル・説明文を取得
    └─ ブログ等 → ページを取得して本文テキストを抽出
    ↓
[Claude API] 要約・タイトル生成・カテゴリー分類・タグ付け
    ↓
[Google Drive] カテゴリー別フォルダにMarkdownファイルとして保存
    ↓
[ナレッジシート] 処理結果（済/エラー・カテゴリ・ファイルリンク）を記録
```

さらに週1回、保存済みナレッジの**巡回メンテナンス**が自動実行される：

```
[GAS] 週1回（月曜4時ごろ）保存済みファイルを巡回
    ├─ 「時事ネタ」で保存から180日超 → 削除（ゴミ箱行き・30日間復元可）
    │   ※「恒久ナレッジ」は何日経っても削除されない（下記参照）
    ├─ ブログ記事 → 再取得し、内容が変わっていたら要約を再生成
    │   （カテゴリが変わったらフォルダも自動移動）
    ├─ X投稿・YouTube → リンク生存確認。消えていたら「リンク切れ」マーク
    │   （要約にナレッジが残っているためファイルは削除しない）
    └─ 実施内容を「巡回ログ」シートに記録
```

### 期限削除の対象は「時事ネタ」だけ

保存時にClaudeが知識の種類を自動判定して記録する：

| knowledge_type | 意味 | 期限削除 |
|----------------|------|---------|
| 恒久 | ノウハウ・原理原則・考え方など時間が経っても価値が落ちない知識 | **されない** |
| 時事 | ニュース・特定バージョンの情報・キャンペーン・トレンドなど鮮度が命の情報 | 180日超で削除 |

判定に迷う場合は「恒久」に倒れる。さらに、ファイルのfrontmatterに
`keep: true` と1行追加すれば、種類に関係なく手動で永久保護できる。
判定情報のない旧形式ファイルも削除されない（安全側）。

### スキル化候補の自動タグ付け

保存時に「AIに繰り返し実行させられる具体的な手順・テクニックか」も
自動判定され、frontmatterに `skill_candidate: true / false` が付く。
AIに「たまった情報からスキル化できそうなものをピックアップして」と
頼むと、このタグを手がかりに候補を素早く洗い出せる。

## 対応ソースと取得内容

| 種類 | URL例 | 要約の元になる情報 |
|------|-------|-------------------|
| X投稿 | `x.com/ユーザー名/status/番号` | 投稿全文（長文投稿も対応）・投稿者・日時 |
| YouTube | `youtube.com/watch?v=…` / `youtu.be/…` / shorts | **動画本編の内容（音声・映像）**※Gemini APIキー設定時。未設定ならタイトル・説明文 |
| ブログ・Web記事 | 上記以外の一般URL | ページタイトル・本文テキスト（先頭8,000字） |

## 出力イメージ

```
出力先フォルダ/
├── AI・LLM活用/
│   ├── 2026-07-23_Claude_Digest_プロンプト設計のコツ.md
│   └── 2026-07-23_zenn.dev_RAG構築の実践記事.md
├── 開発・プログラミング/
│   └── 2026-07-23_チャンネル名_GAS解説動画.md
└── その他/
```

各Markdownファイルは Obsidian でそのまま使える frontmatter 付き
（source / source_type / author / category / tags など）。出力先を
Obsidian vault 内のフォルダにすれば、AIシステム側からナレッジとして
参照できる。

## セットアップ手順

### 1. GASプロジェクトを作成

1. ナレッジシートを開く → 拡張機能 → Apps Script
2. `Code.gs` の内容を貼り付けて保存

### 2. 設定値を編集

`Code.gs` 冒頭の `CONFIG` を編集：

| 設定 | 内容 |
|------|------|
| `SHEET_ID` | 設定済み（ナレッジシートのID） |
| `ROOT_FOLDER_ID` | **要設定**。出力先フォルダのID（Driveでフォルダを開いたときのURL末尾） |
| `CLAUDE_MODEL` | 既定は `claude-sonnet-5`。コスト重視なら `claude-haiku-4-5-20251001` |
| `CATEGORIES` | 分類カテゴリー。自由に編集可 |
| `RETENTION_DAYS` | 時事ネタの保存期限（既定180日）。恒久ナレッジは対象外 |
| `OLD_FILE_ACTION` | 期限切れの扱い。`trash`＝ゴミ箱（既定・30日間復元可）/ `archive`＝`_アーカイブ`フォルダへ移動 |
| `RECHECK_INTERVAL_DAYS` | 各ファイルのリンク・内容チェック間隔（既定30日） |

### 3. APIキーを設定

1. [Anthropic Console](https://console.anthropic.com/) でAPIキーを取得
2. GASエディタ → プロジェクトの設定（歯車） → スクリプトプロパティ
3. プロパティ名 `ANTHROPIC_API_KEY`、値にAPIキーを追加

**（任意）YouTube動画本編の解析を有効にする場合：**

4. [Google AI Studio](https://aistudio.google.com/apikey) でGemini APIキーを取得（無料）
5. スクリプトプロパティに `GEMINI_API_KEY` を追加

設定するとGeminiが動画本編（音声・映像）を視聴して内容をまとめ、
それを元に要約が作られる。未設定でもタイトル＋説明文ベースで動作する。

### 4. 動作確認と定期実行の設置

1. GASエディタで `testRunOnce` を実行（初回は権限承認あり）→ 1件だけ処理される
2. シートのB〜F列とDriveの出力先フォルダを確認
3. 問題なければ `installTrigger` を1回実行 → 以後6時間ごとに自動実行
4. `installMaintenanceTrigger` も1回実行 → 以後週1回（月曜4時ごろ）巡回メンテナンスが自動実行

## シートの列の使い方

| 列 | 内容 | 書き込み者 |
|----|------|-----------|
| A | URL | 拡張機能 |
| B | ステータス（済/エラー） | GAS |
| C | カテゴリー | GAS |
| D | タイトル | GAS |
| E | 処理日時 | GAS |
| F | 保存ファイルURL / エラー内容 | GAS |

## 注意事項

- **Xはタイムライン（`x.com/home`）ではなく個別投稿のURLを保存すること**。
  投稿の詳細ページで拡張機能を使うか、投稿URLを保存する設定にする。
- 非公開アカウント・削除済み投稿・年齢制限付き投稿は取得できない
  （エラーとして記録され、他の行の処理は継続する）。
- YouTube動画本編の解析（Gemini API）は公開動画のみ対応。無料枠は
  1日あたり動画8時間まで。エラー時は自動でタイトル＋説明文ベースに
  切り替わる（処理は止まらない）。
- `GEMINI_API_KEY` 未設定の場合、YouTubeの要約はタイトル＋説明文ベース。
- 会員限定記事・JavaScript必須のページは本文が取得できないことがある
  （その場合もエラーとして記録される）。
- X投稿の画像・動画の中身は解析対象外（付いていることだけ記録される）。
- エラーになった行を再処理したい場合は、B列の「エラー」を消せば
  次回実行時に再試行される。
- 巡回メンテナンスの削除はゴミ箱行きなので30日間は復元できる。
  完全削除が嫌な場合は `OLD_FILE_ACTION: 'archive'` に変えると
  `_アーカイブ` フォルダへの移動になる（`_` で始まるフォルダは巡回対象外）。
- リンク切れになったファイルは削除されず frontmatter に
  `source_status: リンク切れ` が付くだけ。要約自体はナレッジとして残る。
- 巡回の実施記録はナレッジシート内の「巡回ログ」シート（自動作成）で確認できる。
- コスト目安：1件あたり約0.5〜2円（claude-sonnet-5、記事の長さによる）。
