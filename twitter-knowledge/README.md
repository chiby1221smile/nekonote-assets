# Twitterナレッジ自動整理ツール

ナレッジシート（スプレッドシート）に拡張機能で溜まっていくX(Twitter)の投稿URLを、
定期的に自動処理するGASスクリプト。

```
[拡張機能] 投稿URLをナレッジシートに保存
    ↓ 6時間ごとに自動実行
[GAS] 未処理のURLを検出
    ↓
[公開シンジケーションAPI] 投稿本文・投稿者・日時を取得（認証不要）
    ↓
[Claude API] 要約・タイトル生成・カテゴリー分類・タグ付け
    ↓
[Google Drive] カテゴリー別フォルダにMarkdownファイルとして保存
    ↓
[ナレッジシート] 処理結果（済/エラー・カテゴリ・ファイルリンク）を記録
```

## 出力イメージ

```
出力先フォルダ/
├── AI・LLM活用/
│   └── 2026-07-23_username_プロンプト設計のコツ.md
├── 開発・プログラミング/
│   └── 2026-07-23_username_GASの実行時間制限対策.md
└── その他/
```

各MarkdownファイルはObsidianでそのまま使えるfrontmatter付き
（source / author / category / tags など）。出力先をObsidian vault内の
フォルダにすれば、AIシステム側からナレッジとして参照できる。

## セットアップ手順

### 1. GASプロジェクトを作成

1. ナレッジシートを開く → 拡張機能 → Apps Script
2. `Code.gs` の内容を貼り付けて保存

### 2. 設定値を編集

`Code.gs` 冒頭の `CONFIG` を編集：

| 設定 | 内容 |
|------|------|
| `SHEET_ID` | 設定済み（ナレッジシートのID） |
| `ROOT_FOLDER_ID` | **要設定**。出力先フォルダのID（Driveでフォルダを開いたときのURL末尾） |
| `CLAUDE_MODEL` | 既定は `claude-sonnet-5`。コスト重視なら `claude-haiku-4-5-20251001` |
| `CATEGORIES` | 分類カテゴリー。自由に編集可 |

### 3. APIキーを設定

1. [Anthropic Console](https://console.anthropic.com/) でAPIキーを取得
2. GASエディタ → プロジェクトの設定（歯車） → スクリプトプロパティ
3. プロパティ名 `ANTHROPIC_API_KEY`、値にAPIキーを追加

### 4. 動作確認と定期実行の設置

1. GASエディタで `testRunOnce` を実行（初回は権限承認あり）→ 1件だけ処理される
2. シートのB〜F列とDriveの出力先フォルダを確認
3. 問題なければ `installTrigger` を1回実行 → 以後6時間ごとに自動実行

## シートの列の使い方

| 列 | 内容 | 書き込み者 |
|----|------|-----------|
| A | 投稿URL | 拡張機能 |
| B | ステータス（済/エラー） | GAS |
| C | カテゴリー | GAS |
| D | タイトル | GAS |
| E | 処理日時 | GAS |
| F | 保存ファイルURL / エラー内容 | GAS |

## 注意事項

- **拡張機能の保存形式に注意**：処理には個別投稿のURL
  （`x.com/ユーザー名/status/番号`）が必要。`x.com/home` のような
  タイムラインURLはエラーになる。拡張機能は必ず**投稿の詳細ページ**で
  使うか、投稿URLを保存する設定にすること。
- 非公開アカウント・削除済み・年齢制限付きの投稿は取得できない
  （エラーとして記録され、他の行の処理は継続する）。
- 画像・動画の中身は解析対象外（付いていることだけ記録される）。
- エラーになった行を再処理したい場合は、B列の「エラー」を消せば
  次回実行時に再試行される。
- コスト目安：1投稿あたり約0.5〜1円（claude-sonnet-5の場合）。
