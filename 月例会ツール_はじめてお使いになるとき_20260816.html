月例会ツール はじめてお使いになるとき

各支部の運営者向け／使い始めの準備（ログイン → 会員リストの取り込み → 役員の登録 → 会員の情報を埋める → 開催方式を入れる → 過去の主催レポートの取り込み）

1. この資料について

月例会ツールを使い始めるときの準備をまとめた資料です（このうち「会員リストの取り込み」だけは毎月行います）。月例会1回分の進め方（参加者を入れる、テーブル割りをする、名簿を出す）は、別冊の「使い方マニュアル」をご覧ください。

やっていただくのは6つです

順番やることどこで
1ログインするログイン画面
2会員リストを取り込むトップ画面の 会員リストを取り込む
3役員を登録するトップ画面の 05 設定 → 役員 タブ
4会員の情報を埋めるトップ画面の 05 設定 → 会員詳細 タブ
5開催方式を入れるトップ画面の 05 設定 → 支部の設定 タブ
6過去の主催レポートを取り込むトップ画面の 05 設定 → 過去レポート タブ

順番の決まり：会員リストを取り込んでから、過去の主催レポートを取り込んでください

2（会員リストの取り込み）を済ませてから、6（過去の主催レポートの取り込み）を行ってください。逆にすると、取り込んだ過去の記録に会員のお名前が正式な表記で入らず、所属支部の欄も空のままになります。

あとから会員リストを取り込んでも、先に取り込んだ過去の記録は直りません。理由は「7. 過去の主催レポートを取り込む」にあります。

いちばん大事なこと：3まで終われば、月例会は回せます

1（ログイン）から3（役員の登録）までが終われば、その日から月例会の準備に使えます。まずはここまでを済ませてください。

4（会員の情報）は、量が多い作業です。会員の人数ぶん（18名以上）あるので、一度に全部やらなくて構いません。使いながら少しずつ埋めていってください。埋まっていくほど、テーブル割りの精度と 星の評価 の点数がそろっていきます。

この資料に出てこない準備について

支部専用の保存先の用意と、支部名とパスワードでログインできるようにする設定は、画面の裏側の準備として済ませてあります。運営者の側で行っていただく作業はありません。

ただし「会員リストを取り込む」だけは、運営者の側で行っていただきます。最初の1回だけでなく毎月行う作業です。やり方は次の「3. 会員リストを取り込む」にあります。

このツールを新しく入れた直後は、会員リストを1回取り込むまで会員の情報が出てきません（自分の支部の方も、他の支部の方も出ません）。まず取り込みを済ませてください。

2. ログインする

お渡しするのはURLとパスワードの2つです。どちらもこちらからお伝えします。

  1. お渡ししたURLを、パソコンやスマートフォンのブラウザで開きます。
  2. 月例会ツール という見出しの画面が出ます。
  3. 支部名 の欄に、支部名を入力します。「支部」の2文字は付けずに入力してください。
  4. パスワード の欄に、お渡ししたパスワードを入力します。
  5. ログイン を押します。

どちらかが違っていると 支部名またはパスワードが違います と出ます。大文字と小文字は区別されます。前後に空白が入っていないかも確かめてください。

パスワードについて

支部で1つ個人ごとのアカウントはありません。役員の方2〜3人で同じものを共有してください。
こちらで作ります読み違えにくい英数字でこちらが作ってお渡しします。運営者の側で決めていただく必要はありません。
変更はできません画面から変える仕組みはありません。忘れたときや、外部に漏れてしまったときはご連絡ください。お調べするか、新しいものを作ってお渡しします。
外に出さないでくださいURLとパスワードは、支部の役員以外にはお伝えしないでください。この2つを知っている人は、支部のデータを開けます。

5. 会員の情報を埋める

ここは量の多い作業です。一度に全部やらなくて構いません。月例会を回しながら、少しずつ埋めていくことが可能です。

一覧に他の支部の方も並ぶ理由

基本は自分の支部の会員を管理する画面です。会員リストの取り込みで入るのも、自分の支部の会員だけです。

そのうえで、他の支部から月例会に参加してくださった方も、この一覧に残ります。次に来てくださったときに名前と支部がすぐ分かるようにするためです。テーブル割りでも、その方の支部と業種を見て席を決めています。

自分の支部の会員だけを見たいときは、絞り込み欄の右にある 自支部のみ の切り替えを入にしてください。

なお 受講済み研修（自支部のみ）・入会：・準役： の欄は、自分の支部の会員を開いたときだけ出ます。他の支部の方には出ません。

なぜ埋めるのか

入れるもの何に効くか
業種テーブル割りのときに、同じ業種の方が同じ卓に固まらないように分散されます。

TL優先度TLを決めるときに、この方を先に選びます。TL研修受講済み を入にすると出てきます。
入会：星の評価 の受講率を計算する対象（入会から3か月以上たった方）を決めるのに使います。ここが空のままだと、受講率は計算できません。
受講済み研修SU スタートアップ と SD 商談 が 星の評価 の 必須研修受講率（SU+SD） に、FE フロントエンド が TL研修受講済み と組み合わさって フロント+TL研修受講率 になります。SK 集客 と UE 運営 は記録として残ります。

7. 過去の主催レポートを取り込む

これまでNM本部に提出してきた主催レポート（xlsx）を読み込んで、過去の参加記録として残す作業です。取り込むと、星の評価 の参加人数とゲスト割合が過去の月のぶんも出るようになります。

月例会の準備やテーブル割りには関わりません。お手元のレポートがそろってから行っていただければ大丈夫です。

必ず、会員リストを取り込んだあとに行ってください

主催レポートには会員番号しか入っていません。そのため、取り込むときに会員リストを見てお名前と所属支部を補っています。会員リストがまだ入っていないうちに取り込むと、お名前がレポートに書かれた姓と名をつないだ形のまま残り、所属支部の欄は空のままになります。

あとから会員リストを取り込んでも、先に取り込んだ過去の記録は直りません。順番は「会員リスト → 過去の主催レポート」です。

レポートのタブ名は、8桁の数字であることが必須です

読み込むのは、タブ名が8桁の数字になっているタブだけです。年4桁・月2桁・日2桁を続けた形にしてください（例：2026年6月18日 → 20260618）。

8桁の数字以外のタブは読み込みません。「20260618（6月）」のように後ろに文字が付いているものや、「6月」「6月18日」のようなタブ名も対象外です。数字だけの8桁にしてください。

1つのファイルに月ごとのタブが並んでいる場合も、8桁の数字になっているタブを全部読み込みます。8桁の数字のタブが1枚もないファイルは、いちばん左のタブだけを読み込みます。

トップ画面の 05 設定 を開き、過去レポート のタブを押します。過去レポートの取り込み という見出しの画面が出ます。

ステップ1. xlsxをアップロードする（複数可）

  1. xlsxファイルをここにドロップするか、タップして選択してください と書かれた枠に、主催レポートのファイルを置きます。枠を押してファイルを選んでも同じです。複数まとめて選べます。
  2. 選んだファイルの名前が枠の下に並びます。

10. よくあるご質問

全部入れ終わらないと、月例会には使えませんか？

使えます。ログイン・会員リストの取り込み・役員の登録が終わっていれば、その日から月例会の準備に使えます。会員の情報は、使いながら少しずつ埋めていってください。

会員の情報は、途中でやめても大丈夫ですか？

大丈夫です。会員情報を保存する を押したところまでは残ります。次に開いたとき、その続きから埋めていけます。

役員の名前を打ち込む欄が見つかりません

名前は打ち込む形ではありません。（タップして会員を選ぶ） と書かれたところを押すと 会員を選択 の一覧が開くので、その中から選んでください。

役員の固定テーブルは、必ず決めないといけませんか？

決めなくて構いません。固定しない のままにしておくと、テーブル割りのときに自動で決まります。

この内容で更新する と 会員情報を保存する は何が違いますか？

この内容で更新する は、1人ぶんを画面の中で確定するボタンです。これだけでは残りません。ひととおり終えたら、いちばん下の 会員情報を保存する を押してください。役員のほうも同じで、追加する のあとに 役員設定を保存する が要ります。

他支部の方を開くと、研修の欄が出てきません

受講済み研修（自支部のみ） の区切りから下は、自分の支部の方を開いたときだけ出ます。他支部の方には出ません。

カテゴリにあてはまるものがありません

カテゴリを選ぶ のいちばん上にある （カテゴリなし） を選んでください。

一覧の 残り（数）名 は何の数ですか？

カテゴリがまだ入っていない方の人数です。0に近づくほど、テーブル割りの分散が効くようになります。

入会日がわからない人がいます

空欄のままにしておいてください。わかった時点で入れれば、そこから 星の評価 の受講率に反映されます。

すでに取り込んだ開催日の内容を直したいときは？

ご連絡ください。同じ開催日は読み飛ばされるため、入れ直すには先に古い記録を消す必要があります。こちらで消してから、もう一度アップロードしていただきます。

パスワードを忘れました

ご連絡ください。お調べしてお伝えするか、新しいものを作ってお渡しします。画面から変えたり調べたりする仕組みはありません。

あとから見つかった主催レポートは、足せますか？

足せます。05 設定 → 過去レポート のタブで、同じ手順でアップロードして取り込んでください。すでに取り込んだ開催日は読み飛ばされるので、二重に入ることはありません。まだ入れていないレポートだけをアップロードしてください。

過去の主催レポートを、会員リストより先に取り込んでしまいました

ご連絡ください。あとから会員リストを取り込んでも、先に入った過去の記録のお名前と所属支部は直りません。入れ直すには、古い記録を消してから取り込み直す必要があります。

月例会の進め方はどこに書いてありますか？

別冊の「使い方マニュアル」をご覧ください。参加者を入れるところから、テーブル割り・当日の出欠・参加者名簿の出力までが載っています。

次に何をすればよいかわからなくなりました

画面の上にある ? を押してください。その画面の説明が開きます。
