月例会ツールの使い方

各支部の運営者向け／月例会1回分の流れ（参加者を入れる → テーブル割り → 保存 → 当日の出欠 → 紹介者 → 名簿の出力）

1. この画面でできること

月例会1回分の準備から後片づけまでを、この1つのツールで行います。参加者を入れると自動でテーブル割りを作り、当日の出欠をつけ、最後にNM本部提出用の参加者名簿を出すところまでつながっています。

役員の設定・会員の業種の入力など、最初の1回だけ行う準備は、先に「はじめてお使いになるとき」の資料をご覧ください。

月例会の準備を始める前に、その月の会員リストを取り込んでおいてください。やり方は下の「2. 開き方」にあります。

いちばん大事なルール

テーブルは1卓4名または5名で組む決まりです。そのため、参加者が6名・7名・11名のときは自動で割り当てができず、自分でテーブルを決める画面に切り替わります。

これは不具合ではありません。4名と5名の組み合わせでは、その人数をぴったり分けられないためです。切り替わったら 手動で決める を押して、順番に振り分けてください（やり方は「4. テーブル割りをする」にあります）。

2. 開き方

  1. お渡ししたURLを、パソコンやスマートフォンのブラウザで開きます。
  2. 月例会ツール という画面が出ます。
  3. 支部名 の欄に支部名を入力します。「支部」の2文字は付けずに入力してください。
  4. パスワード の欄に、お渡ししたパスワードを入力します。
  5. ログイン を押します。

入力するのは、その端末で最初の1回だけです。次に開いたときは自動でログインした状態に戻ります。詳しくは別冊の「はじめてお使いになるとき」の2章をご覧ください。

  3. 会員一覧 のタブを選びます。
  4. 表の上をクリックして、Ctrl を押しながら A（全部選ぶ）、続けて Ctrl を押しながら C（コピー）を押します。

3. 参加者を入れる（2つのやり方）

トップ画面で 01 新規に定例会準備をする を選び、カレンダーで開催日を選びます。すでに準備を始めた日なら 02 登録済みの定例会を処理する から一覧で選べます。

定例会準備　開催日: （日付） という画面になります。上にタブが2つあり、やりやすいほうを選んで構いません。混ぜて使えます。

やり方1. 参加者入力（1人ずつ入れる）

  1. 名前を入力 と書かれた欄に、名前を入れます。
  2. 追加 を押します。
  3. 下の 参加者リスト（N名） に加わります。（Nのところには今の人数が入ります）

やり方2. まとめて貼り付け（一気に入れる）

グループチャットなどに並んでいる名前を、そのままコピーして貼り付けられます。名前を1行1名で貼り付けてください。 と説明が出ています。

入力例として 山田 太郎 鈴木 花子 のように、1行に1人ずつ並べます。貼り付けたら 一括追加 を押します。貼り付けた文字を消したいときは クリア です。

何人でも貼り付けられます（人数の上限はありません）。

4. テーブル割りをする

テーブル割り　開催日: （日付） の画面になります。参加者を直したくなったら ← 参加者入力に戻る で戻れます。

1. テーブルに入らない人を外す

実行ボタンの上に テーブルに入らない運営メンバー： という欄が出ることがあります（役員を登録しているときだけ出ます）。役職：名前 の形で並ぶので、受付や司会などで席に着かない方にチェックを入れます。チェックした方は割り当てから外れ、結果には テーブルなし（運営メンバー） として並びます。

席に着く方は、チェックを入れないでください。全員にチェックを入れると割り当てるものが無くなり、エラーになります。

2. 自動で割り当てる

ボタンできること
▶ テーブル割り実行1回だけ割り当てを作ります。
3回試行・ベスト採用3回試して、そのうちいちばん良い結果を採用します。時間に余裕があるときはこちらがおすすめです。
手動で決める自動を使わず、自分で1人ずつ振り分けます。

3. 割り当ての決まり

決まり中身
1卓の人数4名または5名です。参加者を4名と5名に分けきれない人数のときは、自動では割り当てず、自分で決める画面に切り替わります。
自動にできない人数6名・7名・11名は、4名と5名の組み合わせで分けられないため自動ではできません。手動で決める画面に切り替わります。
参加者が3名以下全員で1卓になります。この場合だけは3名以下の卓ができます。
役割1つのテーブルにTL（テーブルリーダー）は1名まで、SL（サブリーダー）も1名までです。

4. 手動で決める

手動で決める を押すと 手動テーブル割り のパネルが開きます。

  1. 卓数: の横の － ＋ で、テーブルの数を決めます。
  2. 参加者ごとに テーブルを選ぶ を押して、入るテーブルを選びます。選べるのは テーブル A から順に並んだテーブルと、（割り当てなし） です。
  3. 役割をつける人は 役割を選ぶ を押して、TL（テーブルリーダー） SL（サブリーダー） なし から選びます。
  4. 全員を振り分けたら この内容で保存する を押します。やめるときは 閉じる です。

1人でも残っていると保存できません。（割り当てなし） のままの人がいないか確かめてください。

5. 結果を共有する

割り当てができると テーブル割り結果 が表示され、その下に 共有用テキスト が出ます。これは、そのままグループチャットなどに貼れる形になっています。

  1. 共有テキストをコピー を押します。
  2. コピーしました と出たら、コピーできています。
  3. 連絡に使っているチャットやメールに、そのまま貼り付けて送ります。

6. 履歴に保存する

割り当てが決まったら、履歴に保存して定例会当日へ を押します。これで、この開催日の記録が残ります。

保存は1つの開催日につき1回だけです

同じ開催日でもう一度保存しようとすると この日付のデータは既に存在します（日付）。上書きする場合は既存データを削除してから再実行してください と出ます。作り直したいときは、先に前の記録を消す必要があります。

保存した記録は、トップ画面の 履歴を見る から確かめられます。履歴 の一覧で 詳細を見る を押すと中身が出ます。一覧に戻るときは ← 履歴に戻る です。

直せるのは3ヶ月以内の記録だけです。それより前を直そうとすると 3ヶ月より前の履歴は修正できません（日付） と出ます。

7. 月例会当日（出欠をつける）

当日は 定例会当日　開催日: （日付） の画面を開きます。ここで、実際に来た人・来なかった人を反映します。

欠席の人をつける

出欠変更 の欄に 欠席の人は、名前の横の「出席 ✓」を押すと欠席に変わります。 と書かれています。

  1. 来なかった人の名前の横の 出席 ✓ を押します。
  2. 表示が 欠席 に変わります。もう一度押すと出席に戻ります。

全員が欠席になるような操作はできません。参加者が0名になります。少なくとも1名の参加者が必要です と出ます。

当日に来た人を追加する

  1. テーブルを選択 を押して、入ってもらうテーブルを選びます。
  2. 名前を入力... の欄に名前を入れます。
  3. ＋ 参加者を追加 を押します。

最後に保存する

出欠と追加が終わったら 確定して保存 を押します。これを押さないと、当日の変更が残りません。

8. 紹介者を記録する

誰が誰を連れてきたかを残す画面です。トップ画面の 04 紹介者を記録する から開けます。テーブル割りの画面にある 紹介者を記録する からも開けます。

見出しは 紹介者を記録、説明は ゲストや新会員の紹介者を記録します。 です。

  1. 紹介した人を NM会員IDまたは氏名 の欄に入れます。IDでも名前でも構いません。
  2. 💾 紹介者を保存 を押します。

この画面は、先にテーブル割りを履歴に保存してから使います。保存していないと 先にテーブル割りを履歴に保存してください と出ます。

9. 参加者名簿（NM本部提出用）を出す

月例会が終わったあと、NM本部に出す参加者名簿を作ります。トップ画面の 03 参加者名簿を作る から開きます。

見出しは 参加者名簿出力、説明は 月例会終了後、NM本部提出用の参加者名簿xlsxを自動生成します。 です。xlsxとは、Excelで開ける表のファイルのことです。

  1. レポートを出力する開催日を選んでください と書かれた下の 出力する開催日を選択 を押します。まだ選んでいないときは タップして開催日を選ぶ と表示されています。
  2. 開催日を選んだら 読み込む を押します。
  3. 開催日 と 支部名 の確認表が出ます。合っているか見てください。
  4. レポート生成 を押します。
  5. レポートを生成中...（数十秒かかる場合があります） と出ます。途中で画面を閉じずに待ってください。
  6. できあがると ダウンロード と フォルダを開く が出ます。ダウンロード を押すとファイルが手元に保存されます。

名簿を出せるのは、直近3ヶ月以内の開催日だけです。それより前しかないときは 直近3ヶ月以内の履歴がありません。先に「履歴に保存」を実行してください と出ます。

10. 入力するとどうなりますか

参加者を入れる入れるたびに自動で保存されます。⬤ 保存済み ✓ が出ていれば、途中でブラウザを閉じても消えません。次に開いたとき、トップ画面に （日付）の定例会準備の続きがあります と出て、そこから続けられます。

12. やらないでいただきたいこと

  • 同じ開催日で2回「履歴に保存」をしない　この日付のデータは既に存在します と出ます。作り直すには、先に前の記録を消す手間がかかります。
  • 参加者リストが ⬤ 保存済み ✓ になる前に、テーブル割りへ進まない　保存が終わっていない人が抜け落ちることがあります。表示が変わるまで待ってください。
  • 準備中のデータがあるまま、別の日付で新しく準備を始めない　前の日付で入れていたデータが破棄されます。続きがあるときは、トップ画面の （日付）の定例会準備の続きがあります から 再開する → を押して、先に終わらせてください。
  • 月例会から3ヶ月以上たってから直そうとしない　3ヶ月より前の記録は直せません。直しは月例会のあと、早めに済ませてください。

13. よくあるご質問

参加者が6名なのに、テーブル割りができません。壊れていますか？

壊れていません。テーブルは4名または5名で組む決まりなので、6名・7名・11名は自動で分けられません。手動で決める を押して、自分で振り分けてください。

参加者が3名以下のときはどうなりますか？

全員で1卓になります。ふだんは4名または5名で組む決まりですが、この場合だけは3名以下の卓ができます。

▶ テーブル割り実行 と 3回試行・ベスト採用 は何が違いますか？

▶ テーブル割り実行 は1回だけ作ります。3回試行・ベスト採用 は3回試して、そのうちいちばん良い結果を採用します。

変更 を押して名前を探しても、何も出てきません

検索は 2文字以上で検索します。1文字だけでは出てきません。2文字以上入れてみてください。

「まとめて貼り付け」は何人まで貼れますか？

人数の上限はありません。何人でも貼り付けられます。

途中でやめてしまいました。最初からやり直しですか？

やり直しではありません。参加者は自動で保存されています。トップ画面に （日付）の定例会準備の続きがあります と出るので、タップして再開する または 再開する → を押してください。

先月の分を直したいのですが

3ヶ月以内であれば直せます。トップ画面の 履歴を見る から 詳細を見る で開いてください。3ヶ月より前は 3ヶ月より前の履歴は修正できません（日付） と出て、直せません。

参加者名簿はいつまで出せますか？

直近3ヶ月以内の開催日まで出せます。月例会が終わったら、早めに出しておくと安心です。

次に何をすればよいかわからなくなりました

画面の上にある ? を押してください。このアプリの流れ の説明が開きます。

会員リストの取り込みや役員の設定はどこでやりますか？

どちらもトップ画面から行います。会員リストの取り込みは毎月、役員の設定は最初の1回だけです（役員が変わったときは直します）。手順は「はじめてお使いになるとき」の資料にあります。

ご不明な点は、ネコノテ 山下美樹まで Messenger または LINE でご連絡ください。
